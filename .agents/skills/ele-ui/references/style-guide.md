# Ele-H5 Style Guide

Ele UI 面向易宿酒店预订平台的    前端 UI 风格包。

## Visual Tokens

```css
:root {
  --bg: #f7f7f4;
  --ink: #171717;
  --muted: #64645f;
  --line: #deded6;
  --paper: #ffffff;
  --soft: #eeeee8;
  --green: #1f8a5b;
  --blue: #2768a7;
  --amber: #b17418;
  --red: #b64f42;
  --shadow: 0 18px 50px rgba(35, 35, 30, 0.08);
  --radius: 8px;
}
```

- 背景使用浅米色 28px 网格；卡片使用白色纸面、1px 边框、8px 以下圆角和轻阴影。
- 绿色用于主线索：阶段、active tab、关键结论、check 状态。
- 蓝色只用于链接或引用来源；红/黄只用于风险、局限或状态语义。
- 不使用紫蓝渐变、光球、复杂插画、emoji 和无意义装饰。


## Typography And Layout

- 字体：`ui-sans-serif, -apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", "Microsoft YaHei", sans-serif`。
